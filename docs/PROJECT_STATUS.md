## 数据位置

小说正文和用户数据保存在浏览器 IndexedDB 数据库 `yejian-library` 中。阅读设置和当前阅读书籍标识保存在同一站点的浏览器本地存储中。

Android 版使用 App 内 WebView 的 IndexedDB；章节导出与书架备份写入手机 `Documents/YejianExports`。

项目目录不包含用户导入的小说正文，也不会修改原始 TXT。

## 已知限制

- 数据默认只存在当前浏览器和当前站点地址，需要手动导出备份迁移。
- 文件夹导出依赖 File System Access API，推荐 Chrome 或 Edge。
- 页面刷新会恢复阅读状态，但会中断正在执行的导出任务。
- 自动编码识别优先 UTF-8 和 GB18030；少见编码需要手动选择。
- 章节识别依赖常见标题格式；无标题文本会按固定长度分段。
- 正文高亮目前按所选文字匹配；同一段落中完全相同的文本优先标记首次匹配。
- Android 听书依赖手机系统安装可用的中文 TTS 引擎。
- 当前 APK 使用调试签名，适合自用测试，不用于应用商店发布。
- 截至 2026-08-28，`npm audit` 报告 20 个依赖告警（2 个低危、3 个中危、15 个高危），主要来自当前开发工具链；未使用 `npm audit fix --force`，以避免破坏兼容性。
