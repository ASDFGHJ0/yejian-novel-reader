# 稳定性更新与验收

本轮将本地页间地址固定为 http://localhost:3010。端口被占用时应报错退出，不能自动换到其他端口。

## 迁移旧书架

旧书架仍保存在同一个浏览器的 http://localhost:3000 下，不会自动出现在 3010。
先停止占用 3000 的其他项目，在本项目运行 npm run dev -- --port 3000，
打开旧地址导出书架备份；停止后正常启动页间，在 3010 使用“恢复备份”。
确认数据完整前不要清除旧地址的网站数据。安卓书架不受端口调整影响。

## 听书诊断

阅读页提供“听书诊断”：检查中文支持和声音列表、朗读固定测试句、复制诊断结果。
诊断不包含小说正文。现有接口无法读取手机媒体音量或默认引擎名称，会明确标记限制。
构建成功不代表真机发声成功。需要真机验证：首次播放、暂停继续、切速、
锁屏至少十分钟、锁屏跨章、定时停止、回前台进度。当前跨章和定时仍依赖网页调度，
不能声称已经保证锁屏跨章和锁屏定时。

## 回归检查

运行 node --test scripts/test-core.mjs，覆盖编码、分章、命名、逐句切分和缓存隔离。
发布前运行 npm run build 与 npm run android:sync，再编译 APK。
新版 APK 必须在真机通过上述检查后才标记为稳定版。
