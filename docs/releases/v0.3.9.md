# 页间 v0.3.9

## 普通用户下载

- **安卓手机和平板**：下载 `yejian-android.apk`，点击安装或覆盖旧版本。
- **Windows 本地网页版**：下载 `yejian-web-windows.zip`，解压后双击 `启动页间网页版.cmd`。
- **开发者源码**：使用 GitHub 自动提供的 Source code 压缩包。

本地网页版第一次启动会自动安装运行组件，需要 Node.js 22 或更高版本并保持联网。小说、书架、阅读进度、书签和笔记均保存在设备本地。

## v0.3.9 更新

- Android 恢复已验证能够正常发声的原生 TTS 插件。
- 使用 Android 原生语音队列进行逐句朗读。
- 自动阅读速度精简为慢速、标准、较快、快速四档。
- 目录关闭按钮固定在侧栏右上角。
- 新增本地网页版双击启动脚本与独立下载包。
